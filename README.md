# TechnoBank UI

React + Vite frontend for TechnoBank.

## Installation

**Windows:**
```bash
setup.bat
```

**Linux/macOS:**
```bash
chmod +x setup.sh
./setup.sh
```

## Running

```bash
npm run dev
```

## Configuration

API URL: defaults to `http://localhost:8000`

To change, set before running:
```bash
VITE_API_BASE_URL=http://your-api-url npm run dev
```
